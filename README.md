# Garis Start calendar

Public race times for the Indonesian [Jadwal Moto3](https://jadwal-moto3.pages.dev/) calendar. The scheduled job checks the [official MotoGP calendar](https://www.motogp.com/en/calendar) every three hours and keeps the latest successful data. Each round links to its official source. Times are in UTC. The checked field records when the job last retrieved the schedule. Event and session times can change.
